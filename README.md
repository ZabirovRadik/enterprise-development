# RealEstateAgencyApp

Система для управления объектами недвижимости, клиентами и заявками.

## Архитектура

### Domain
Ядро приложения с бизнес-сущностями:
- `Counterparty` - контрагенты и клиенты
- `RealEstateObject` - объекты недвижимости
- `Request` - заявки и обращения

### Contracts
Модели данных для API:
- DTO для операций создания и обновления
- DTO для чтения и отображения
- Интерфейсы сервисов

### Infrastructure
Доступ к данным и внешним сервисам:
- **Persistence** - настройка Entity Framework (AppDbContext)
- **Migrations** - управление версиями схемы базы данных
- **Repositories** - реализации репозиториев для работы с сущностями

### Application
Бизнес-логика и координация:
- Сервисы с основной логикой приложения
- Валидация данных и бизнес-правила
- Координация работы между репозиториями и API

### API
Веб-интерфейс приложения:
- REST API контроллеры для всех сущностей
- Обработка HTTP запросов
- Централизованная обработка ошибок

### ServiceDefaults
Общие настройки и конфигурация для всех проектов решения.

### Tests
Тесты для проверки функциональности.

## Технологии
- .NET 8
- C# 12
- Entity Framework Core 8
- ASP.NET Core Web API
- MS SQL Server

## Основные функции

- Управление объектами недвижимости
- Работа с контрагентами и клиентами
- Обработка заявок и обращений
- REST API для интеграции
